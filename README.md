## Danes notes for danes
Steps if changes are made.

```
// stash
git stash

// fetch
git fetch

// pull from main
git pull origin main

// apply stash
git stash apply

// stage changes
git add .

// commit
git commit -m "<sample message>"

// push
git push

# Merge dev branch to main

// build
npm run deploy
```
